## 🧠 What Is REMNANT

- 🤖 **Persistent Minds agent** — built on [Minds by Animoca Brands](https://www.animocabrands.com/minds), not a dashboard
- 🧭 **Remembers forgotten needs** — audience asked for it in 2022, asked again in 2026, different words: is it real, or coincidence?
- 🔬 **Scientist, not vibes** — competing hypotheses (H1–H4), pre-registered experiments, deterministic verdicts
- 🕰️ **Time-aware by design** — every remnant is a hypothesis with provenance, evidence strength, and a full transition log
- 🔍 **Probe-proof honesty** — real data labeled real, synthetic labeled synthetic, uncertainty always shown

---

## 🔥 What I'm Shipping

### 🧬 Discovery Engine
Cross-language need discovery via a transparent concept glossary — "Can you make a beginner ZK tutorial?" links to "How do I start building with zero knowledge?" as a *candidate*, never auto-merged, never claimed as proven continuity.

### ⚖️ H1–H4 Accounting
Every remnant holds four competing explanations — persistent need, new cohort, temporary trend, semantic coincidence — each with supporting and contradicting evidence. Contradicting evidence is never suppressed.

### 🧪 Pre-Registered Experiments
Metric, threshold, target population and duration locked *before* observation. The verdict is arithmetic: `observed 0.067 >= pre-registered 0.040 → CLEARED`.

### 🧠 Minds Persistence + Recovery
Every belief-critical change is mirrored into the Minds agent's conversation. A fresh session can recover the belief narrative from the Mind itself — even after a store wipe. Verified live against a real Minds agent.

### 📡 Autonomous Observatory
A background observer revisits dormant remnants on an interval, surfaces candidates, and writes its own audit trail. No page load required on the durable deployment.

### 📥 Real Data Imports
YouTube comments, GitHub issues, Discord exports — imported straight from the website, full provenance (source, author, URL, timestamp), through the same discovery pipeline.
